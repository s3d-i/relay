# 评估范围讨论（虚构的人类输入示例）

下列 prompt 与回答均是教学用虚构文本，不是用户真实发言。

原始示例 prompt：

> 我怀疑 conditioning 的提升可能只是评估归一化不同。先检查已有结果，不要开新训练。

agent 的理解：前半句是待验证怀疑，后半句是明确的本次优先级与资源约束。先让当前审计 subagent 检查已有材料，不打断它去做扩容实验。

示例追问：

> 如果已有结果的条件不一致，这次是否允许重新评估已有 checkpoint？

原始示例回答：

> 先把差异列清楚。重新评估等我看完再定。

人的决定：本次仅审计。未回答的条件性问题：历史条件无法复原时如何补证。它应留待讨论，不作为自动开跑的任务。
